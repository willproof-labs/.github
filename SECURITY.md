# Security policy / Politique de sécurité

**Please report vulnerabilities privately** with the **Report a vulnerability** button of
the affected repository (Security tab), never in a public issue. You will get an answer
as soon as possible; please give us a reasonable delay before any public disclosure.

**Signalez les vulnérabilités en privé** avec le bouton **Report a vulnerability** du
dépôt concerné (onglet Security), jamais dans une issue publique. Vous aurez une réponse
dès que possible ; laissez-nous un délai raisonnable avant toute divulgation publique.

Each project documents its own threat model in its documentation.
Chaque projet décrit son propre modèle de menaces dans sa documentation.
